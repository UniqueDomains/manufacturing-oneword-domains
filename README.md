## 🧱 Field summary

- `domain`, Fully qualified domain name.
- `status`, Current acquisition state for the domain in the public extract.
- `purchase_price`, Visible purchase price when available.
- `renewal_price`, Visible renewal price when available.
- `attractiveness`, Public composite naming band used as a decision-support signal.
- `demand`, Public buyer-pressure band when available.
- `length`, Character count without the TLD.
- `registrar`, Registrar name when known.
- `created_at`, Creation timestamp when known.
- `expires_at`, Expiry timestamp when known.
- `status_verified_at`, When status was last established against the registry. Null means never checked.

See [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) for full definitions and types.

## ⚠️ Methodology and caveats

This is a set of one-word domain names tied to the manufacturing keyword, drawn from 506 different TLDs. With a median ask near $558, the group ranges from affordable niche extensions to higher-priced mainstream ones. Because the pool spans so many endings, the same manufacturing-related word can appear under multiple TLDs at very different price points. Comparing ask price, renewal cost, and how easily a name reads or spells helps narrow this list to the strongest candidates for either a quick brand launch or a longer-term hold.

- 167,816 one-word manufacturing domain names across 506 TLDs
- Median ask of $558 per domain in this selection
- Compare pricing and renewal cost before committing
- Spot brandable, ownable names for a fast shortlist
